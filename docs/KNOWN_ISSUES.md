# Known issues and limitations

**Phase 1: PARTIAL.** Updated 2026-09-13 UTC. Package 8 builds, the newer authored-exit source passes all 13 Unreal tests without test warnings/failures, and isolated fresh-process storage passes. These results do not close the remaining player-experience requirements.

## Open implementation and quality gaps

1. **The owner rejected the graphics as far below acceptable.** Generated spacecraft, station and secondary meshes/materials are provisional, not selected final art. A substantial art replacement pass is required. Preserve the supplied Acornaut. Package 8's panorama showed soft/oversized stars and a weak forward nebula; seam/pole/readability checks remain open. The space treatment, HUD, VFX and synthesized audio also need integrated art/mix review.
2. **Character presentation remains provisional.** Package 8 uses the same derivative at scale 1.5 through the 2.4-second authored exit and walk. Automated contact/handoff passes at 30/60/144 Hz; guarded Slomo 0.1 native replay showed seated/airborne/landing/standing and post-exit interaction. This does not establish natural docking/camera quality. The initial pose resets to Pilot time zero rather than blending current idle. Original assets are preserved; tail distortion and continuous motion/art acceptance remain open.
3. **Station presentation remains rudimentary.** Native consoles, service machinery, a primitive moving Mica avatar, ambience and a story/reward beacon exist. There is no finished skeletal vendor or recorded dialogue. Acornaut reactions are cooldown-limited subtitle captions.
4. **Station 2 completion acceptance remains open.** Package 7 has a native live-statistics panel and direct services/save/discard choices. Save/relaunch retained Cooling; no Wave 11 is offered. Discard was displayed, not invoked. No owner-approved victory/XP policy or retry-appeal result is implied.
5. **Input needs physical-device acceptance.** Adapter tests cover movement at 30/60/120/144 Hz, boost/brake, directional dodge collision and manually triggered weapons. They call gameplay methods directly. Keyboard/mouse feel, controller parity, hold/toggle, live-menu focus, reconnects and comfortable camera behavior remain unverified.
6. **Natural balance and Director fairness are unproven.** Required Wave 10 admission and event route checks now have deterministic regression coverage. The accelerated journey uses 12-second waves, enlarged durability and forced/assisted objectives. It does not establish purchase cadence, natural event routes, reaction windows or compound-climax readability.
7. **Storage still needs fault coverage.** Real locked-suspension/account replacement failures preserve bytes and permit retries with once-only XP. Package 7 also passed native Save & Quit/Continue at both prepared stations and resumed death/account readback. Seeded/assisted sessions do not establish natural play. Corrupt-account recovery, forced interruption, disk-full/short writes and staged-readback failure remain unverified. Only the generic local Windows backend is supported; no multi-slot transaction or automatic backup manager exists.
8. **UI/audio need integrated acceptance.** Package 7 exposed overlapping service/reward prompts; package 8's guarded replay verified suppression during exit and service E afterward. Boundary/vendor menus and package 6 mouse/controller 1.2 readback passed narrow checks, but maximum scale, busy-scene readability and physical comfort remain open. Alarm has a six-second cooldown and captions an 18-second cooldown. Station QA was muted and proves no listening/mix quality.
9. **Some tunable content remains native.** Fixed hazard/enemy/pickup/encounter catalogs are editable, but weapon/utility/contract policies, reward offerings, station layout and menus still require C++ changes. Native factories and synchronous loading limit designer extension.
10. **Representative performance remains open.** Package 7 passed scoped station/storage routes, separate from package 4 performance. Package 4 Waves 1–3 measured about 119.96 FPS at a 120 FPS cap, p99 9.119 ms, maximum 10.898 ms and zero flight frames above 16.667 ms. Startup reached 2,174.921 ms. Both climaxes, stations and full-run RAM/VRAM remain unmeasured. See [PERFORMANCE.md](PERFORMANCE.md); no representative 60 FPS or higher-refresh acceptance is claimed.
11. **Clean-PC portability remains unverified.** Package 8 replaced package 7's older runtime with Microsoft-signed x64 14.51.36247.0 for toolset 14.51; source/destination hashes, signature and provenance receipt passed independent checks. No installer or clean-PC run was performed, and there is no app-local CRT. The host's installed runtime still limits portability evidence.
