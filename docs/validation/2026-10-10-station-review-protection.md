Station visual reviews now have an explicit private save-profile preparation and pre-Play path guard in [StationReviewProfile.py](../../Scripts/StationReviewProfile.py). This addresses the retained Central189 settings-save preservation failure. The earlier settings bytes are unavailable; no restoration or reset is claimed, and the cause remains unconfirmed.

CPU preparation creates a fresh GUID under `.agent/local/StationReview`, byte-copies and reads back all current `.sav` files from both production locations, and checks the production file list/hashes again after copying. Three files were backed up; the second location was absent. The review User/Saved profile is seeded from the editor project's copies. The launch plan always includes `-RenderOffscreen`, `-SaveToUserDir`, an explicit `-UserDir`, a private layout and a unique review-root argument. Preparation never launches an editor or modifies production saves/permissions.

`verify_before_play()` checks the actual engine ProjectUserDir/ProjectSavedDir, launch flags, GUID/marker, production manifest and absence of links/junctions. It rejects an already-running Play session. The private current-station capture wrapper calls this guard before preparing any future review. Fresh preparation is required after production saves change; the helper never restores a backup automatically.
