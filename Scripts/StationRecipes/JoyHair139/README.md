import or completion stages.** Output-directory and exact-hash guards intentionally
refuse another run. Only path constants and trailing blank lines differ from executed source; AST comparison
checks every other statement. Private inputs, receipts, failed runs, Blender/ABC
derivative, native backups and logs are in `.agent/local/StationRefinement/JoyHair139`.

  preserve raw source curves/body/materials and save/reload a CPU head preview.
- ImportHair143 is the retained partial import: groom saved, binding count check
  premature, BP untouched. It is evidence of that stage, not a successful installer.
- CompleteHair153 is the bounded continuation of inspected partial assets. It

  returns to normal ticks. The warm158 receipt is a prerequisite, not a bypass.

  not change lighting, population, ray tracing, scalability or scene content.

AlembicHairImporter; final binding verification used an offscreen editor with a
